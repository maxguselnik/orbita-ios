# Проверка Орбиты

Цель — убедиться, что работает, до того как пользователь поставит игру на iPhone.

## 1. Выбрать сцены по диффу

`git status` + `git diff --stat main...` (и незакоммиченное). Сцены передаются приложению как `-screen <имя>` (`App/Core/DemoScenario.swift`):

| Что менялось | Сцены |
|---|---|
| `App/UI/Map/`, манёвры | `map mapManeuver mapLuna` |
| `App/UI/HUD/` | `flight ascent orbit rcs` |
| `App/UI/Tutorial/` | `tutorial tutorialLuna` |
| Ангар, центр, исследования | `hangar hangarBoosters spaceCenter research` |
| `App/Render/` | `ascent transonic reentry orbit lunaSurface` |
| Экипаж | `crewGallery crewCalm crewPanic` |
| Только физика / тесты / документы | без снимков |
| Крупное или неясно | `default` (набор `screens.txt`) |

Не больше ~8 сцен: каждая занимает около 7 с.

## 2. Запустить

```bash
.claude/skills/check/check.sh <сцены...>
```

По умолчанию гоняются только тесты, затронутые диффом от main (`scripts/affected-tests.sh`: изменённые тесты и тесты, где упомянуты типы из изменённых файлов; правка ядра физики — вся физика). Скрипт печатает, какие наборы выбраны. Полный прогон — `check.sh --full [сцены...]`: только если пользователь попросил или правка задевает общее ядро; иначе полный прогон делает CI.

Сборка занимает несколько минут: запускать через Bash с `run_in_background: true` и ждать уведомления, не опрашивать. Скрипт останавливается на первом провале и печатает ошибки и путь к логу в `build/logs/`.

Если провал: прочитать лог, починить и запустить заново, пока всё не станет зелёным. Если тест упал из-за чужого незакоммиченного изменения, а не из-за текущей задачи, не чинить молча, а сказать об этом пользователю.

## 3. Посмотреть снимки

Каждый `screens/<сцена>.png` открыть через Read (они уже повёрнуты в landscape). Проверить:
- нет пустого или чёрного экрана, сцена соответствует названию;
- HUD не обрезан и не перекрывает сам себя, текст по-русски и без «…» там, где не задумано;
- изменённый элемент виден и выглядит так, как согласовано в макете.

Если упала сцена (`*-crash.ips`), это провал: разобрать стек.

Если изменение интерактивное (жесты, кнопки, урок по шагам), дополнительно пройти его через инструмент iOS-симулятора: `launch` с `build/Build/Products/Debug-iphonesimulator/Orbita.app`, затем tap/swipe и screenshot.

## 4. Отчёт пользователю (по-русски, кратко)

- ✔/✘ OrbitPhysics: N тестов
- ✔/✘ Сборка (предупреждения = ошибки)
- ✔/✘ AppTests: N тестов
- Снимки: какие сцены, что замечено (1 строка на сцену; проблемы — первыми)
- Что проверить руками на iPhone 15 Pro: ощущения, 120 Гц, хаптика, звук (симулятор их не покажет)

Самые показательные снимки отправить через SendUserFile.
