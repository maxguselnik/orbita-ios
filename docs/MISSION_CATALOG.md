# Каталог заданий карьеры

80 шаблонов по запросу пользователя 2026-10-15. Это каталог для реализации, не список уже доступных кнопок. Правила — [CAREER_ECONOMY.md](CAREER_ECONOMY.md). Генератор выдаёт только задачи с работающей механикой, доступным оборудованием, достижимым телом и выполнимым сроком.

**B** — весь финансовый бюджет в тысячах кредитов, включая использованный целевой аванс. **Н** — предложенный максимум новой науки: **В** — одноразовая веха, **Д** — реальные новые данные. Если веха/предмет уже изучены, соответствующая наука равна нулю; она не прибавляется ещё раз поверх науки из отчёта. Нулевые научные награды намеренны: коммерческая работа финансирует экспедиции. Числа — начальная версия баланса.

## Ограничения генерации и приёмка

- Внутри каждой группы есть цепочки открытий, но повторяемые SRV/TECH не заменяют продвижение главной программы.
- Разные цели используют разные объекты и результаты; одна научная квитанция может подтвердить связанную цель, но не удваивает науку. Взаимоисключающие заказы отмечаются общей группой.
- Научный потенциал SYS/EXP пересчитывается по реальному архиву и множителям новых тел; таблица не выдаёт плоский повторяемый бонус за один пролёт.
- Для каждого шаблона до реализации зафиксировать тип повторяемости, срок/отсутствие срока, источник финансирования, залог, репутацию, технологические зависимости и точное условие доставки. Использовать ECO-03 и сохраняемые ID.
- В ручной приёмке пройти обычное выполнение, пропуск промежуточного этапа, гибель участника, подмену объекта, повторную загрузку, повторное открытие итогов и два совместимых заказа. Научные и финансовые квитанции должны оставаться единственными.
